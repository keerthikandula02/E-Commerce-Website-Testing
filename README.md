# 🛒 E-Commerce Website Testing

A portfolio-ready **Manual Testing project** demonstrating QA practices for an e-commerce web application.

## 🎯 Objective
Validate critical shopping journeys including product search, product details, cart, checkout, payments, order confirmation, and regression scenarios.

## 🧪 Testing Coverage
- Functional testing
- UI testing
- Positive & negative testing
- Boundary value analysis
- Equivalence partitioning
- Smoke & sanity testing
- Regression testing
- Usability testing
- Cross-browser checklist

## 📊 Sample Scenarios
| ID | Scenario | Expected Result |
|---|---|---|
| EC-001 | Search valid product | Matching products displayed |
| EC-002 | Add product to cart | Cart count and item updated |
| EC-003 | Remove item from cart | Item removed and total recalculated |
| EC-004 | Apply invalid coupon | Clear validation message shown |
| EC-005 | Checkout with missing address | User cannot continue |
| EC-006 | Successful checkout | Order confirmation displayed |
