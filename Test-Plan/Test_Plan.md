# E-Commerce Test Plan

## Scope
Search, catalog, product details, cart, coupon, checkout, payment validation, order confirmation and regression.

## Out of Scope
Production payment processing and real customer data.

## Entry Criteria
Build is deployed to test environment and critical dependencies are available.

## Exit Criteria
All critical/high priority scenarios executed; no open blocker/critical defects; agreed regression suite completed.

## Deliverables
Test cases, execution summary, defect reports and evidence screenshots.
